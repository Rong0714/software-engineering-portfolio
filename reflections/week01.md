## Task 1
"Software" is a set of instructions and data that tells a computer what to do, "Engineering" adds a sense of 'how', i.e how it runs, how to deliver a working, maintainable system on time and on budget. A software that has worked well for me was Visual Studio Code, it works well mainly down to the simplicity and good visuals as well as layout.
A software that has frustrated me was Microsoft Access in many ways, Major flaws include outdated code, underwhelming visuals and over all hard understanding.

A Software success I've experienced was the completion of a website I done for a Javascript project for university, my first guess of what a developer might have done differently is use react.js.
A software failure I've personally done was creating a mod for a game called Minecraft using Java, original creation was a success, but when updating it to newer versions for it to be compatible was a failure as newer versions uses different concepts/code, which i gave up pretty quickly, a developer might do it differently by learning the newer versions.
